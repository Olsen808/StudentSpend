# StudentSpend — V1 prototype

A simple browser-based expense tracker for university students.

## Features
- Add expenses with a description, amount, category and date.
- View current-month spending, budget and remaining balance.
- Set or edit a monthly budget.
- Filter expenses by category and month.
- Delete an expense.
- Basic input validation and responsive layout.
- Saves data in the browser using localStorage.

## Run locally
1. Download `index.html`.
2. Open it in a modern browser (Chrome, Firefox, Edge or Safari).
3. No installation, server or external libraries are required.

## Important
This is V1, an initial prototype. Data is stored locally in the browser and is not synced across devices. It is not connected to a bank account. Do not enter sensitive financial or personal information.
